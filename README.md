# lkh-data

Hourly leaderboard data for the **[Legion Key History](https://github.com/bez-wow/legionkeyhistory)**
World of Warcraft addon (Legion 7.3.5, Tauri).

The file `LeaderboardData.lua` in the **[latest release](https://github.com/bez-wow/lkh-data/releases/latest)**
is the Tauri Mythic+ leaderboard, read from the Tauri armory API and refreshed about every hour.
You don't need to download it yourself: the addon's `LKH Updater.cmd` keeps it up to date.

To get the addon, see **[bez-wow/legionkeyhistory](https://github.com/bez-wow/legionkeyhistory)**.
